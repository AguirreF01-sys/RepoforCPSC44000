## Project Description

This program searches for **“near misses”** to **Fermat’s Last Theorem**.

Fermat’s Last Theorem states that for any integer \( n > 2 \), there are no positive integers \( x, y, z \) such that:
x^n + y^n = z^n

While exact solutions do not exist for \( n > 2 \), this program searches for combinations that come **very close** to satisfying the equation.
